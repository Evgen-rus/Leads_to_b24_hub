# Инструкции для агента

## Перед изменением

1. Прочитай `ARCHITECTURE.md` и связанные тесты.
2. Проверь рабочее дерево и не затрагивай несвязанные изменения.
3. Не читай и не выводи `.env`, webhook, Google credentials, телефоны или реальные строки лидов.

## Инварианты

- Один код обслуживает все проекты; клиентские различия задаются в `config/*.yaml`.
- Секреты задаются только через переменные окружения. В YAML хранится имя переменной, но не webhook.
- Любое непустое значение в колонке `Статус_Б24` блокирует отправку строки.
- Если колонка результата отсутствует, она создаётся справа с заголовком `Статус_Б24`.
- Уникальность доставки: `(project_code, source_id)`. Старые клиентские SQLite не импортируются.
- После создания Bitrix-лида его ID и URL сначала сохраняются в SQLite, затем ссылка записывается в Google Sheets.
- Повторный запуск не создаёт второй лид: используется SQLite и `ORIGINATOR_ID`/`ORIGIN_ID` в Bitrix.
- Позиция weighted-cycle сохраняется между запусками. Назначенный строке ответственный не меняется при retry.
- `--dry-run` не пишет в Google Sheets, Bitrix или таблицу deliveries.
- Не запускай реальные Google/Bitrix вызовы без явного подтверждения.
